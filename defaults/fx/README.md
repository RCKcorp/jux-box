# Effets audio locaux

Ce dossier est volontairement vide dans le dépôt public.

Vous pouvez y placer localement vos propres fichiers `.mp3`. Au démarrage, JuxBox copie les effets présents ici vers `uploads/fx/` s'ils n'existent pas déjà.

N'ajoutez que des fichiers que vous avez le droit d'utiliser et de redistribuer.
